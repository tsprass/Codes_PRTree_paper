# Codes_PRTree_paper

Code for the PRTree-related papers: comparison of PRTree and CART on regression datasets with missing values.

> **Status:** work in progress. Only the scripts below have been reviewed and published; the remaining analysis scripts will be added after review.

Run the scripts from the repository root.

## Optional: UCI metadata exploration

These scripts are **optional**. The metadata is already included in the repository (`data/uci_all_metadata.rds`), so run `01` only if you want to fetch a fresh copy of the metadata from the UCI repository, and `02` only if you want to explore that metadata.

| File | Description |
|---|---|
| `01 - Pre-processing.R` | Queries the UCI Machine Learning Repository API (dataset IDs 1 to 700) and collects the metadata of each dataset: name, number of instances/features, tasks, area, feature types, missing-value flag, target column(s) and data URL. Saves the result to `data/uci_all_metadata.rds` and `data/uci_all_metadata.csv`. Partial results are saved every 20 datasets found. |
| `02 - Filter.R` | Exploratory script for the metadata. Loads `data/uci_all_metadata.rds` and filters the datasets: regression tasks with missing values (`with_missing`) and regression tasks with more than 300 and fewer than 30,000 instances and 3 to 99 features (`regression_metadata`). Also prints summary statistics and plots the distributions of instances, features, missing values and target availability. |

## Data analysis

Scripts used to produce the results of the paper.

| File | Description |
|---|---|
| `03 - functions.R` | Helper functions sourced by the analysis scripts (see below). Not meant to be run on its own. |
| `04 - Prepare datasets.R` | Downloads the datasets with missing values used in the main analysis from the UCI repository (`Crime`, `Garment`, `Auto`, `Automobile`) and adds `Ozone` from the `mlbench` package. For `Crime`, the 5 non-predictive attributes documented by UCI are dropped. Each dataset is prepared with `prepare_data()` and saved to `data/individual/`. Prints a summary table (response, n, p and percentage of missing values). |
| `05 - Run analysis - parallel.R` | Runs 15-fold cross-validation of CART and PRTree (across combinations of fill types, proxy criteria, and distributions) in parallel for each dataset in `data/individual/`. Saves individual results in `results/<dataset>.rds`, detailed execution logs in `results/<dataset>.log`, and consolidates all results into `results/prtree_cart_raw.rds` and `.csv`. Supports checkpointing/resuming. |

### Functions in `03 - functions.R`

| Function | Description |
|---|---|
| `fetch_safe()` | Downloads a UCI dataset by ID with `ucimlrepo`, converts `"?"` to `NA`, recovers numeric columns and identifies the response variable. Returns `NULL` (with a warning) if the download fails. |
| `prepare_data()` | Removes rows with missing response, drops non-numeric predictors, flags natural missing values in the predictors and converts `X` and `y` to numeric matrix/vector. Stops with an error if the response variable is not found. |
| `nmin()` | Computes the minimum leaf size (a proportion of the training size or a fixed value). |
| `get_folds()` | Builds the cross-validation fold indices (stratified by missingness or random) with a fixed seed. |
| `run_cart_cv()` | Cross-validation of CART (`rpart`, pruned by minimum cross-validated error). Returns the test RMSE per fold. |
| `run_pr_cv()` | Cross-validation of PRTree (`PRTree::pr_tree_cv`). Returns the test RMSE per repetition. |
| `run_dataset_experiment()` | Runs CART and all PRTree configurations (fill type, proxy criterion and distribution) on one dataset and returns the raw RMSE values in a data frame. |

The `config` argument of these functions is the object created by `PRTree::pr_tree_control_cv()` (it accepts any argument of `PRTree::pr_tree_control()`, plus `method`, `n_rep` and `stratify`).

## Data

| Path | Description |
|---|---|
| `data/uci_all_metadata.rds` | UCI metadata generated by `01 - Pre-processing.R` (provided, so running `01` is optional). |
| `data/individual/` | Datasets with missing values used in the main analysis: `Crime` (UCI 183), `Garment` (UCI 597), `Auto` (UCI 9), `Automobile` (UCI 10) and `Ozone` (`mlbench`). |
| `data/individual_complete/` | Complete (no missing values) datasets used in the semi-synthetic studies: `Concrete` (UCI 165). |
| `datasets_tested_not_in_paper.txt` | Record of the datasets that were tested during the project but are not part of the main analysis in the paper. |

## Requirements

R packages used by the scripts above: `dplyr`, `jsonlite`, `ggplot2`, `gridExtra`, `ucimlrepo`, `purrr`, `mlbench`, `parallel`, `rpart`, `tibble` and `PRTree`.

`get_folds()` calls the internal function `PRTree:::.sample.stratified_folds`, which is not exported, so results may depend on the installed PRTree version.
